# Диагностическая проба Jev — 8 ноября 2026

Подготовлен `evals/jev_probe.py`. Живых обращений к TypeSafe не было; текущий запрет
пользователя на платные запросы сохраняется. Это подготовка A-03, не завершение
оценщика: объяснения и evidence Jev пока не проверяет, в сдачу его ответы не идут.

## Что сравниваем

Один публичный вымышленный диалог `fixtures/synthetic/conversation.json`, та же
версия рубрики, что в пробе Gemini. У Gemini 3.5 Flash Lite совпали 4/8 ответов
этого примера. Это известный диагностический пример, не независимый holdout и
не Ground Truth организаторов. Результат Jev пока неизвестен.

`jev-1.14.0` получает весь актуальный snapshot рубрики и отдельный `Choice` для
каждого критерия. Варианты, включая разрешённый N/A, строятся из конфигурации;
числа C04/C06 выбираются из допустимых ступеней, не из среднего `Score` Jev.
Эталонные ответы и технический ID диалога в запрос не входят. Ответы сравниваются
после запроса; confidence сохраняется отдельно и не меняет баллы.

CLI принимает только встроенный synthetic пример. У него нет параметра файла
диалогов, DEV/PROD, произвольного endpoint, автоматического повтора или mock fallback.
Основная фабрика провайдеров, UI, scorer и официальный экспорт не изменены.
Отчёт прямо помечен `submission_eligible=false`; он не выдумывает объяснения,
N/A reason или evidence для преобразования в готовую `EvaluationOutput`.

## Тариф и предел первой пробы

По [актуальным условиям TypeSafe](https://help.typesafe.ai/articles/5187202169-how-much-does-jev-cost)
вход стоит $0,042 за миллион токенов, выход бесплатный. Бесплатных/пробных кредитов
нет. Расход запроса и необходимая сумма пополнения аккаунта — разные величины;
пополнение и автосписание не разрешены этой подготовкой.

Предлагаемый первый запуск: **1 запрос, 1 synthetic диалог, лимит расхода $0,01**,
таймаут 60 секунд, без повторов, длинного контекста, реальных транскриптов и аудио.
До отправки резервируется $0,002752512: 65 536 входных токенов × $0,042 / 1 000 000.
Это консервативный резерв для опубликованного стандартного контекста 64k,
условный на актуальность тарифа, а не лимит биллинга на стороне TypeSafe.
После таймаута резерв не возвращается; расход без usage остаётся неизвестным.
Фактический счёт не выводится из примерной цены: `actual_billed_usd=null`.
Тариф подтверждён на 08.11.2026; в другую дату live блокируется до перепроверки.

## Команды

Из корня выбранной интеграционной копии с установленными зависимостями:

```powershell
$env:PYTHONPATH = 'backend;.'
python -m evals.jev_probe --output artifacts/private/jev-prepared
```

Эта команда не создаёт HTTP-клиент и не требует ключа. Сохраняет запрос, хеши
диалога/рубрики/запроса, версии инструкции/pipeline и состояние `prepared`.
Существующий каталог не перезаписывается. По умолчанию бюджет равен нулю.

Следующая команда **только после явного разрешения пользователя** на платный
synthetic запрос и бюджет, с ключом `TYPESAFE_API_KEY` из локальной среды:

```powershell
python -m evals.jev_probe --execute --approve-synthetic-transfer --approved-budget-usd 0.01 --output artifacts/private/jev-live-pilot
```

Ключ создавать только в [официальной консоли](https://console.typesafe.ai/keys),
не вставлять в чат, исходники или shell history. Не использовать похожие домены
посредников. Приложение `LIVE_EVAL_ENABLED` для этой команды включать не требуется.
У живого запуска новый каталог; подготовленный пакет нельзя случайно отправить
повторно через возобновление. Резерв и попытка записываются до POST. При аварии
статус `started` означает возможный расход и требует проверки, а не перезапуска.

Проверяются модель, полный набор критериев, допустимые варианты, конечные
вероятности, распределение и максимальный выбранный вариант. Тело ответа ограничено
64 КиБ. Redirect, HTTP 402/429/5xx, неверный JSON, повторяющиеся JSON-поля и timeout
дают `failed`; текст внешней ошибки и ключ не печатаются. Технически валидный
выбор всё равно может быть содержательно неверным.

## После первой пробы

Разобрать каждое расхождение. Если вариант перспективен, согласовать отдельный
лимит и одинаковые новые примеры для сравниваемых моделей; заранее отделить
настройку от holdout. Для настоящего pipeline разработать и проверить evidence
и объяснения, затем отдельно согласовать передачу DEV/контроля. Нельзя автоматически
оправдывать выбор Jev текстом другой модели или считать их согласие доказательством.

Другие кандидаты с бесплатными API-квотами: Groq `openai/gpt-oss-120b` и
`qwen/qwen3.8-27b`; [официальные лимиты](https://console.groq.com/docs/rate-limits).
Сейчас для них опубликованы 1 000 запросов/день, 8 000 токенов/мин и
200 000 токенов/день. Фактические лимиты проверяются в конкретном аккаунте;
это не обещание, что весь DEV поместится. Их качество здесь ещё не измерялось.

Спецификации: [Choice](https://docs.typesafe.ai/primitives/choice),
[модели и контекст](https://docs.typesafe.ai/models),
[формат ответа](https://docs.typesafe.ai/sdk/python/api/types/responses).
