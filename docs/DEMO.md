фактическую выдачу PROD подтверждают организаторы. До 12:00 завершить push и проверку.

## 23-й час: новые данные

Организаторы предоставляют доступ к 10 неизвестным контрольным чатам; способ
получения объявляют отдельно. Не предполагать заранее тот же DEV endpoint/group_id.
Загрузить через тот же pipeline, зафиксировать полный source manifest, применить
согласованный официальный snapshot checklist, дождаться результатов.
Не использовать заготовки по ID, ручные overrides как оригинальные AI-ответы
или непрерывную настройку на контроле. Сохранить provenance/usage/failures.

В этот же час, с запасом до стоп-кода:

1. Сформировать `results/prod/results.json`: ровно 10 исходных ID, включая честные
   `status: "error"` при неуспехе; без mock, пропусков и ручной подмены AI.
2. Офлайн проверить оба файла: формат, полный ID-set, типы/шкалы/N/A, evidence,
   общий scorer, C08, official snapshot, исходный AI и фактическую модель.
3. Проверить обезличенность rationale/error и точный staged diff.
4. Выполнить commit **и push обоих файлов в сдаваемую ветку до стоп-кода**.
5. Открыть оба пути в публичном GitHub commit по ссылке, переданной организаторам,
   убедиться в доступности и соответствии SHA. Наличие только локального commit
   или файлов в другой ветке не подтверждает сдачу.

## До наступления 24-го часа: фиксация

- Проверить `git status`, согласованный набор проверок и финальный commit.
- Выполнить `python scripts/freeze.py` с обязательными параметрами ниже в сдаваемом checkout.
- Проверить `artifacts/private/freeze.json`: git SHA и применённые версии.
- Подтвердить, что публичный commit совпадает со сдаваемой версией.
- Убедиться, что этот commit уже содержит оба проверенных файла DEV/PROD.
- После стоп-кода исходники не менять. Новые данные и checklist через UI
  на защите обрабатываются на зафиксированной версии; это не разрешает позднюю
  сдачу или исправление обязательных JSON. Их deadline уже прошёл.

Абсолютный срок — 8 ноября 2026 в 12:00 по Астане, подтверждён пользователем.
Не запускать freeze-скрипт сейчас ради видимости сдачи.

В момент сдачи подставьте реальные идентификаторы и путь к экспортированному snapshot
активного чек-листа. Команда требует чистый Git checkout:

```powershell
.\.venv\Scripts\python.exe scripts/freeze.py --provider ACTUAL_PROVIDER --model ACTUAL_MODEL_ID --instruction-version v1 --pipeline-version v1 --checklist-version-id ACTUAL_VERSION --checklist-snapshot data/private/active-checklist.json
```

`ACTUAL_*` — значения команды, не готовая конфигурация. Экспорт текущего snapshot
из хранилища входит в процедуру C-05. Метаданные freeze локальны; сам скрипт не блокирует Git
и не экспортирует/валидирует результаты, не делает commit/push и не отправляет
ссылку организаторам. Эти действия C выполняет до фиксации.

## Что назвать честно

Для платной модели — название и приблизительная стоимость одной оценки,
включая retries/verify/repair. Неизвестная стоимость не равна нулю.
Для audio без mapping — переход к message и доступ к записи, без обещания точного seek.
При пропущенной проверке — причина, а не зелёная отметка. Синтетические примеры
явно обозначаются; реальные данные не выводятся в незащищённое публичное приложение.
