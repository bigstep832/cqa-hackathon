## Проверка арифметики независимо от scorer

Добавлен `backend/tests/workflow/test_submission_a04.py`. Он перебирает **5184**
допустимые комбинации значений официальных восьми критериев. Для каждой комбинации
экспорт сравнивается с арифметическим oracle, где веса, максимумы и допустимые
значения переписаны непосредственно из приложения организаторов. Oracle не вызывает
проверяемый scorer для вычисления ожидаемого результата. Проверяются также точные
типы исходных значений, публичные ID и независимость C08 от балла.

Тест использует только синтетические диалоги и режим репетиции; официальные
`results/dev/results.json` и `results/prod/results.json` он не создаёт.
Дополнительная независимая проверка AJV покрыла 76 структурных и граничных случаев.
Существующие регрессии C покрывают исходные ID, чужие snapshots, provenance,
апелляции, ошибочные/прерванные задания, конкурентный экспорт и фиксацию выборки.
Первый офлайн-прогон: **360 Python-тестов прошли**; Ruff без замечаний,
mypy проверил 39 файлов. Зависимость Starlette выдала предупреждение о будущей
смене HTTP-клиента TestClient; ошибок или пропущенных тестов не было.

Команда Python из корня интеграционной копии, `PYTHONPATH=backend;.`:

```powershell
python -m pytest backend/tests/domain backend/tests/evaluation backend/tests/workflow/test_submission.py backend/tests/workflow/test_submission_storage.py backend/tests/workflow/test_submission_a04.py
```

## Граница готовности

Это завершённое ревью контракта и реализации, а не свидетельство готовности
несуществующих официальных файлов. Перед C-05 для каждого фактического DEV/PROD
нужны экспорт и повторная валидация по неизменной выборке, смысловая проверка
пояснений/evidence и проверка персональных данных. Regex и JSON Schema не заменяют
чтение пояснений. Затем оба файла должны быть закоммичены, опубликованы и открыты
по публичному SHA до **8 ноября 2026, 12:00 по Астане**.

В живом A-02 пояснение **D33/C01** процитировало имя оператора. Автоматический
проверяющий пропустил это имя, поэтому успешный технический экспорт строки
не является разрешением её публиковать. Теперь реализовано явное скрытие отмеченных
фрагментов публичного rationale по SHA-256 исходного пояснения. Оно не позволяет
передать новый текст, балл, ответ или evidence; список правок фиксируется вместе
с границей экспортируемых заданий. Порядок — [EXPORT](EXPORT.md).

На отдельной копии реальной SQLite проверена 21 строка: изменён только личный
фрагмент D33/C01. Исходные оценки, баллы, доказательства, эталоны и первоначальная
БД остались неизменными. Проверяющий: `Codex, review authorized by A`.
Это частная проверка строк, не официальная выгрузка из 65 записей или её публикация.

После этих изменений, профилей и упаковки запроса полный backend прошёл
**552 теста** на `22914c4`; Ruff/mypy и public-file guard прошли.
Защита сохранности не заменяет смысловой просмотр всех окончательных пояснений.

Диагностическое сравнение с командной разметкой A-02 не является Ground Truth жюри
и не даёт права вручную подставлять эталоны в исходные AI-результаты.
