# CQA — Conversation Quality Analytics

Общий репозиторий команды из трёх участников. Этап 0 находится в подготовке.
Цель — воспроизводимая оценка операторских диалогов по изменяемой рубрике,
с доказательствами и прозрачным расчётом баллов.

Начните с `AGENTS.md`. Инструкции запуска и статус проверок будут зафиксированы
после сборки минимального каркаса. Реальные данные и секреты не входят в репозиторий.
