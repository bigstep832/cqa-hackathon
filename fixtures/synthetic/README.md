# Синтетические примеры

Все тексты созданы для этого репозитория. Они не взяты из DEV/control и не содержат
реальные сведения о клиентах или действующие регламенты Freedom Broker.

`conversation.json` — вымышленный учебный чат; `answers.json` — явно ручные mock-ответы.
`demo.json` генерируется вызовом `build_demo_payload()` из этих данных и текущего
`config/checklists/default.v1.json`. Это тестовый результат, не доказательство качества AI.

Mock проверяет содержание snapshot, а не только ID. Он отказывает для других текстов,
DEV/control, другого чек-листа или live mode. Новый критерий проверяется отдельно
доменными тестами; его реальная AI-оценка — задача A.

Сценарий ожидает W=65, сумму 55.5, итог 85.38. Факты учебного интерфейса не следует
переносить в реальные рекомендации по продуктам компании.
